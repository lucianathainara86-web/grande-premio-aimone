Para jogar online: escolha seu apelido e crie ou entre em uma sala. A professora pode compartilhar o link da sala e os alunos entram pelo celular sem criar conta. Esta versão usa a configuração Firebase já utilizada no Grande Prêmio Aimone. Para testar sem internet: selecione “Teste em abas do mesmo navegador”.
⚙️ Configuração técnica (somente professora)

Configure um projeto gratuito no Firebase com Authentication → Sign-in method → Anonymous habilitado e Realtime Database criado. A configuração pública do Firebase já está incorporada neste arquivo. Não é necessário preencher nada. A configuração pública não é senha; nunca cole chaves privadas de servidor. Publique este HTML em HTTPS (ex.: GitHub Pages), crie a sala e use Copiar link para os alunos, que adiciona apenas o código da sala ao endereço. Leia as regras e os cuidados de privacidade abaixo.

🔐 Segurança do multiplayer — versão de teste

Esta versão separa dados da professora e dos pilotos. Antes de jogar online, publique as regras correspondentes do arquivo firebase_regras_gp_teste.json no Realtime Database. Não use regras que liberem escrita em toda a sala. Teste com apelidos fictícios e supervisão: respostas e pontuação ainda são verificadas no aparelho do jogador, não no servidor. A expulsão e o bloqueio funcionam para os clientes normais desta versão, mas não são uma barreira antifraude contra alguém que modifique o código ou obtenha uma nova identidade anônima.

📖 Instruções para usar com a turma

Para um teste rápido, abra este HTML no mesmo navegador em várias abas. Crie a sala em uma aba e use o código nas demais. Para jogar a distância, publique esta versão na sua página GitHub Pages já configurada. O arquivo isolado enviado pelo WhatsApp não sincroniza os celulares. O modo online precisa de internet.

Os alunos não precisam criar contas: o Firebase usa autenticação anônima automática. A professora pode ser espectadora e controlar a corrida, ou entrar como um dos cinco pilotos. No modo online, ela pode copiar um único link para os alunos; a configuração pública já está incluída na página, sem exigir que cada aluno a digite. Não use nomes completos dos alunos nem compartilhe a configuração com credenciais privadas.

O progresso da garagem fica no navegador. Em modo online, perder os dados do navegador pode apagar os desbloqueios; não é um sistema de recuperação permanente de contas. A sala aceita até cinco pilotos simultâneos, além da professora como espectadora.
