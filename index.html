📖 Instruções para usar com a turma

Para um teste rápido, abra este HTML no mesmo navegador em várias abas. Crie a sala em uma aba e use o código nas demais. Para jogar a distância, você precisa configurar um projeto Firebase e hospedar este HTML em HTTPS; só enviar o arquivo pelo WhatsApp não sincroniza aparelhos.

Os alunos não precisam criar contas: o Firebase usa autenticação anônima automática. A professora pode ser espectadora e controlar a corrida, ou entrar como um dos cinco pilotos. No modo online, ela pode copiar um único link para os alunos; a configuração pública vai no próprio link, sem exigir que cada aluno a digite. Não use nomes completos dos alunos nem compartilhe a configuração com credenciais privadas.

O progresso da garagem fica no navegador. Em modo online, perder os dados do navegador pode apagar os desbloqueios; não é um sistema de recuperação permanente de contas. A sala aceita até cinco pilotos simultâneos, além da professora como espectadora.
